# Seeker — Windowsローカルファイル検索

**Seeker** は、フォルダ内のファイル名・パス・本文を索引化して検索する、Windows向けの独立したローカル検索MVPです。検索画面はWebブラウザで表示しますが、**ファイルはインターネットへ送信しません**。AnnoLink・XRServer・Ollama・Pythonとは独立して動作します。

> **評価版 v0.5.3** — まず多くの方に試していただき、検索漏れ・検索速度・使い勝手を検証する段階です。検索結果の正確性や数十万件規模の性能を保証するものではありません。

## 使い始める（一般利用者）

1. GitHub ActionsまたはGitHub Releaseから **`Seeker-win-x64-portable-v0.5.3.zip`** を入手します。ソースZIPではなく、**実行ファイル入りの配布ZIP**を選んでください。
2. ZIP全体を、書き込み可能な場所（例：`%USERPROFILE%\Documents\Seeker`）に展開します。`Program Files` には置かないでください。
3. **`Seeker.exe` をダブルクリック**します。サーバーが起動し、既定のブラウザで `http://127.0.0.1:20801` が開きます。
4. 画面右上の設定から「検索対象の管理」を開き、検索するフォルダの絶対パス（例：`D:\技術資料`）を入力して「追加」を押します。フォルダは「索引待ち」に表示されます。
5. 「索引を作成・更新」を押します。件数、進捗％、終了通知を確認できます。正常に索引作成できたフォルダは「登録済みディレクトリ」に移ります。「閉じる」で検索画面へ戻ります。
6. 検索語を入力し、ファイル名をクリックすると、このPCの関連付けアプリでファイルを開きます。
7. **Seekerのコンソールウィンドウを閉じると終了**します。`Ctrl+C` でも終了できます。

初回にWindowsのセキュリティ警告が出る場合があります。配布元を確認し、不審なファイルは実行しないでください。バイナリのコード署名は未対応です。

ヘルプは画面右上の **「ヘルプ ?」** から開けます。インターネット接続なしで使用できます。

## 主な機能

| 項目 | 内容 |
|---|---|
| フォルダ登録 | フォルダの絶対パス入力。ローカル・UNCに対応 |
| 索引 | 初回走査、更新ファイルの差分再解析、削除ファイルの反映。手動実行 |
| 検索 | ファイル名・保存パス・抽出した本文を検索 |
| 検索モード | 自動、キーワード（スペース区切り）、自然言語（Kuromoji） |
| ランキング | 一致条件数の多い順。同条件数では近接性を考慮（先頭800候補のみ） |
| 表記揺れ | 全半角や一部カタカナ表記揺れ、数値＋単位の空白や `mm`/`ミリ` 等 |
| 結果画面 | ファイル名、元のフルパス、本文の一致周辺／冒頭抜粋、強調表示、件数区分 |
| ファイル起動 | 対応形式は関連付けアプリで開き、それ以外はExplorerで選択 |
| 索引進捗 | 総件数、処理済み件数、進捗％、終了／エラー通知 |
| ヘルプ | 画面内のヘルプと本README |

**検索例**：`モーター 過熱 改造`、`最大4.2 mm 交換判定3.0mm`、`搬送装置のベルトが蛇行する`。

Seekerは、検索語の意味をAIが推測するシステムではありません。**数値の大小比較**（`3mmを超える` が4mmに一致するか等）、高度なNOT・AND構文、AI意味検索、OCR、形状認識は未実装です。

## 本文索引の対応ファイル

| 拡張子 | 本文索引 | 備考 |
|---|---|---|
| `.pdf` | 対応 | テキストを含むPDFのみ。スキャンPDFのOCRは非対応 |
| `.docx` | 対応 | Word本文の段落文字列（画像内文字は対象外） |
| `.xlsx` | 対応 | Excelセル値、共有文字列など。画像内文字は対象外 |
| `.pptx` | 対応 | PowerPointスライドの文字列 |
| `.txt`, `.csv`, `.tsv`, `.md`, `.log` | 対応 | UTF-8、BOMありテキスト等。Shift-JISは未保証 |
| `.json`, `.xml`, `.html`, `.htm` | 対応 | テキストとして検索 |
| `.ini`, `.cs`, `.js`, `.css`, `.sql`, `.yml`, `.yaml`, `.php` | 対応 | テキストとして検索 |
| `.doc`, `.xls`, `.ppt` | ファイル名・パスのみ | 旧Office形式の本文抽出は未対応 |
| `.dwg`, `.dxf`, `.step`, `.stp`, `.glb`, `.gltf` | ファイル名・パスのみ | CADや3Dの内容・形状は解析しない |
| `.png`, `.jpg`, `.jpeg`, `.gif`, `.bmp`, `.tiff`, `.webp` | ファイル名・パスのみ | OCR未対応 |
| その他 | ファイル名・パスのみ | 認識できる形式はすべてファイルとして索引登録 |

**制限**：ファイルサイズが40MiBを超える場合は本文を索引化しません。本文の索引化は先頭120,000文字までです。パスとファイル名はどちらの場合も検索対象です。暗号化・破損・読み取り権限のないファイルの本文は検索できないことがあります。

## 対応環境・実行条件

| 項目 | 要件 |
|---|---|
| OS | **Windows 10/11 x64**（Windows x64向けビルド。Windows Serverは未検証） |
| CPU | x64（Intel/AMD）。ARM64は未検証 |
| ブラウザ | Edge / Chromeなど、ローカルHTTPを表示できるブラウザ |
| ポート | **127.0.0.1:20801** が未使用であること。他PCから接続不可 |
| 保存先 | **書き込み可能なフォルダ**。SQLite DBをEXEと同じ階層に作成 |
| 配布方法① | `Seeker-win-x64-portable`：自己完結型。**配布先に.NETの追加インストール不要** |
| 配布方法② | `Seeker-win-x64-framework`：`Seeker.exe` + `Seeker.dll` 等。**ASP.NET Core Runtime 8 x64**が必要 |
| ファイル権限 | 登録したフォルダを、現在のWindowsユーザーが読み取れること |
| インターネット | 利用時は不要。**開発時のNuGet復元**などには必要 |
| メモリ・ディスク | ファイル数・抽出文字量で変動。数十万件規模の必要量は未測定 |

Windows x64以外の利用、複数ユーザー共有、NASへの大規模一斉アクセスは検証していません。Seeker本体のフォルダそのものは検索対象にできません。親フォルダを登録した場合はSeeker本体のフォルダを自動的に除外します。索引作成時には初めに対象ファイル数を数え、次に解析するため、初回は時間がかかる可能性があります。

## DBの保存場所・既存ユーザーの移行

**v0.5.0から**、起動した `Seeker.exe` と同じディレクトリに、`index.sqlite`（および実行時の `index.sqlite-wal`, `index.sqlite-shm`）が作成されます。**索引には抽出した本文が含まれます**。DBは秘密情報として管理してください。GitHubへコミットしないでください。

v0.4.1以前は `%LOCALAPPDATA%\ATINDE\Seeker\index.sqlite` に保存していました。既存のファイル登録・索引を移行する場合は、**両バージョンを停止してから**以下を実行します（新しいDBがすでにある場合は中止されます）。

```powershell
powershell -ExecutionPolicy Bypass -File .\Migrate-LegacyIndex.ps1 -ExeDirectory "C:\Users\YOURNAME\Documents\Seeker"
```

元のDBは削除しません。古いDBの移行が不要なら、この作業は必要ありません。索引を作り直す場合は新規にフォルダを登録してください。

## 開発・ビルド（GitHubソース利用者）

必要：**.NET 8 SDK**。Windows x64推奨。コードはC# / ASP.NET Core / SQLite FTS5 / PdfPig / Lucene.NET Kuromojiで構成されています。`NuGet`のパッケージ復元が必要です。

```powershell
# ソースのあるディレクトリで実行
dotnet restore .\src\Seeker\Seeker.csproj
dotnet build .\src\Seeker\Seeker.csproj -c Release
powershell -ExecutionPolicy Bypass -File .\Start.ps1
```

Windows向けの**EXEとDLLの2種類の配布ZIPを生成**する場合：

```powershell
powershell -ExecutionPolicy Bypass -File .\Publish.ps1
```

生成物（ZIPを展開すると `Seeker.exe`、`wwwroot`、日本語 `Readme.txt` などが入っています。**既存の実行フォルダへ上書き展開せず、新しいフォルダへ展開してください**）：

```text
release/
  Seeker-win-x64-portable-v0.5.3.zip   (self-contained EXE package)
  Seeker-win-x64-framework-v0.5.3.zip  (EXE + DLL package)
```

`Publish.ps1` は索引DBを含む既存の実行フォルダを上書きせず、毎回一時領域でZIPを作成します。元ファイルと索引DBを配布ZIPに含めないことも検査します。`release` 以下の過去の配布フォルダは更新されないため、配布ZIPを新しいフォルダへ展開して動作確認してください。GitHub Actionsの `.github/workflows/windows-release.yml` は、Windowsでビルド・簡易テスト・配布ZIP作成・Artifactのアップロードを行います。**GitHubへのアップロードやRelease作成自体は自動実行しません。**

## セキュリティと既知の制限

- 外部ネットワークには公開せず、127.0.0.1に限定しています。ユーザー認証・他PCからのアクセスは未実装です。
- 読み取り対象のファイルはコピーしませんが、抽出された文字列はSQLite索引に保存します。
- 未対応拡張子はファイルの起動を避け、Windows Explorerで選択します。
- 大規模フォルダの全走査・大量の短い検索語は、遅延やI/O負荷が発生する場合があります。
- 検索インデックスは自動監視していません。更新時は手動で「索引を作成・更新」を実行してください。
- OCR、AI、同義語推測、クリック学習、ファイル内容の編集は行いません。
- **GitHubへの公開前に、ソースの権利・ライセンスおよび第三者パッケージの通知義務を確認してください**。手順は [`docs/GITHUB-PUBLISHING.md`](docs/GITHUB-PUBLISHING.md) を参照してください。
