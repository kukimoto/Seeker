# Seeker — Windowsローカルファイル検索

**Seeker** は、フォルダ内のファイル名・パス・本文を索引化して検索する、Windows向けの独立したローカル検索MVPです。検索画面はWebブラウザで表示しますが、**ファイルはインターネットへ送信しません**。

> **評価版 v0.5.3** — まず多くの方に試していただき、検索漏れ・検索速度・使い勝手を検証する段階です。

## 使い始める（一般利用者）

1. [GitHub Releases](https://github.com/kukimoto/Seeker/releases/tag/v0.5.3) から **`Seeker-win-x64-portable-v0.5.3.zip`** をダウンロードします。
2. ZIP全体を、書き込み可能な場所（例：`%USERPROFILE%\Documents\Seeker`）に展開します。`Program Files` には置かないでください。
3. **`Seeker.exe` をダブルクリック**します。既定のブラウザで `http://127.0.0.1:20801` が開きます。
4. 画面右上の設定から「検索対象の管理」を開き、検索するフォルダの絶対パス（例：`D:\技術資料`）を入力して「追加」を押します。追加したフォルダは「索引待ちのフォルダ」に表示されます。
5. **「索引を作成・更新」** を押します。処理件数・進捗率・終了状態が表示されます。正常に索引作成できたフォルダは「登録済みディレクトリ」に移り、削除ボタンが表示されます。完了後、「閉じる」を押して検索画面へ戻ります。
6. 検索語を入力します。検索結果のファイル名をクリックすると、対応形式はWindowsの関連付けアプリで開きます。それ以外の形式はエクスプローラーで選択表示します。
7. Seekerを終了するときは、起動したコンソールウィンドウを閉じます。`Ctrl+C` でも終了できます。

初回にWindowsのセキュリティ警告が出る場合があります。配布元を確認し、不審なファイルは実行しないでください。バイナリのコード署名は未対応です。

ヘルプは画面右上の **「ヘルプ ?」** から開けます。インターネット接続なしで使用できます。

## 主な機能

| 項目 | 内容 |
|---|---|
| フォルダ登録 | フォルダの絶対パス入力。ローカル・UNCに対応 |
| 索引 | 初回走査、更新ファイルの差分再解析、削除ファイルの反映。手動実行 |
| 検索 | ファイル名・保存パス・抽出した本文を検索 |
| 検索モード | 自動、キーワード（スペース区切り）、自然言語（Kuromoji） |
| ランキング | 一致条件数の多い順。同条件数では近接性を考慮（先頭800候補のみ） |
| 表記揺れ | 全半角や一部カタカナ表記揺れ、数値＋単位の空白や `mm`/`ミリ` 等 |
| 結果画面 | ファイル名、元のフルパス、本文の一致周辺／冒頭抜粋、強調表示、件数区分 |
| ファイル起動 | 対応形式は関連付けアプリで開き、それ以外はExplorerで選択 |
| 索引進捗 | 総件数、処理済み件数、進捗％、終了／エラー通知 |
| ヘルプ | 画面内のヘルプと本README |

**検索例**：`モーター 過熱 改造`、`最大4.2 mm 交換判定3.0mm`、`搬送装置のベルトが蛇行する`。

Seekerは、検索語の意味をAIが推測するシステムではありません。**数値の大小比較**（`3mmを超える` が4mmに一致するか等）、高度なNOT・AND構文、AI意味検索、OCR、形状認識は未実装です。

## 本文索引の対応ファイル

| 拡張子 | 本文索引 | 備考 |
|---|---|---|
| `.pdf` | 対応 | テキストを含むPDFのみ。スキャンPDFのOCRは非対応 |
| `.docx` | 対応 | Word本文の段落文字列（画像内文字は対象外） |
| `.xlsx` | 対応 | Excelセル値、共有文字列など。画像内文字は対象外 |
| `.pptx` | 対応 | PowerPointスライドの文字列 |
| `.txt`, `.csv`, `.tsv`, `.md`, `.log` | 対応 | UTF-8、BOMありテキスト等。Shift-JISは未保証 |
| `.json`, `.xml`, `.html`, `.htm` | 対応 | テキストとして検索 |
| `.ini`, `.cs`, `.js`, `.css`, `.sql`, `.yml`, `.yaml`, `.php` | 対応 | テキストとして検索 |
| `.doc`, `.xls`, `.ppt` | ファイル名・パスのみ | 旧Office形式の本文抽出は未対応 |
| `.dwg`, `.dxf`, `.step`, `.stp`, `.glb`, `.gltf` | ファイル名・パスのみ | CADや3Dの内容・形状は解析しない |
| `.png`, `.jpg`, `.jpeg`, `.gif`, `.bmp`, `.tiff`, `.webp` | ファイル名・パスのみ | OCR未対応 |
| その他 | ファイル名・パスのみ | 認識できる形式はすべてファイルとして索引登録 |

**制限**：ファイルサイズが40MiBを超える場合は本文を索引化しません。本文の索引化は先頭120,000文字までです。パスとファイル名はどちらの場合も検索対象です。暗号化・破損・読み取り権限のないファイルの本文は検索できないことがあります。

## 対応環境・実行条件

| 項目 | 要件 |
|---|---|
| OS | **Windows 10/11 x64**（Windows x64向けビルド。Windows Serverは未検証） |
| CPU | x64（Intel/AMD）。ARM64は未検証 |
| ブラウザ | Edge / Chromeなど、ローカルHTTPを表示できるブラウザ |
| ポート | **127.0.0.1:20801** が未使用であること。他PCから接続不可 |
| 保存先 | **書き込み可能なフォルダ**。SQLite DBをEXEと同じ階層に作成 |
| 配布方法① | `Seeker-win-x64-portable`：自己完結型。**配布先に.NETの追加インストール不要** |
| 配布方法② | `Seeker-win-x64-framework`：`Seeker.exe` + `Seeker.dll` 等。**ASP.NET Core Runtime 8 x64**が必要 |
| ファイル権限 | 登録したフォルダを、現在のWindowsユーザーが読み取れること |
| インターネット | 利用時は不要。**開発時のNuGet復元**などには必要 |
| メモリ・ディスク | ファイル数・抽出文字量で変動。数十万件規模の必要量は未測定 |

Windows x64以外の利用、複数ユーザー共有、NASへの大規模一斉アクセスは検証していません。Seeker本体のフォルダそのものは検索対象にできません。親フォルダを登録した場合はSeeker本体のフォルダを自動的に除外します。索引作成時には初めに対象ファイル数を数え、次に解析するため、初回は時間がかかる可能性があります。



## セキュリティと既知の制限

- 外部ネットワークには公開せず、127.0.0.1に限定しています。ユーザー認証・他PCからのアクセスは未実装です。
- 読み取り対象のファイルはコピーしませんが、抽出された文字列はSQLite索引に保存します。
- 未対応拡張子はファイルの起動を避け、Windows Explorerで選択します。
- 大規模フォルダの全走査・大量の短い検索語は、遅延やI/O負荷が発生する場合がある**かも**しれません。
- 検索インデックス**は自動監視していません**。 更新時は手動で「索引を作成・更新」を実行してください。
- OCR、AI、同義語推測、クリック学習、ファイル内容の編集は行いません。
